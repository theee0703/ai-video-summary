# 雲端每日影片：執行步驟（給排程任務裡的 Claude 看）

目標：每天自動做一支 3～5 分鐘的 AI／晶片新聞摘要影片，繁體中文配音，推到 KY 手機。
這是「雲端版」：沒有原片畫面，只有文字畫面加 Gemini 配音。Mac 版（有原片）另外在 KY 的 Mac 上做。

所有回覆、檔案說明、最後總結一律用**繁體中文**。

## 1. 檢查環境
`bash cloud/setup.sh`。最後一行必須是 200。不是 200 就停下，用繁體中文回報「Gemini 連不上，請確認排程跑在 Default 環境且網路密鑰還在」。

## 2. 選題
- 用網路搜尋找過去 24～48 小時 AI、半導體、晶片相關的重要新聞或深度訪談（例如輝達、台積電、Google TPU、OpenAI、Anthropic、出口管制、資料中心）。
- 看 `days/` 底下過去 7 天的 `script.json` 的 `topic`，避免重複。
- 只挑一個主題，要能用 3～5 分鐘講清楚。至少讀 2 個來源原文（用網頁讀取工具）。

## 3. 寫稿：`days/<今天日期 YYYY-MM-DD>/script.json`
格式：
```json
{"date":"2026-11-23","title":"一句話標題","topic":"主題（給去重用）",
 "sources":[{"name":"Reuters","url":"https://..."}],
 "slides":[{"head":"段落標題","lines":[{"show":"畫面中文字","en":"English subtitle","say":"實際要念的字"}]}]}
```
規則：
- 先講結論，再白話解釋。開場第一段就說「今天發生什麼、為什麼重要」。
- 總長 600～900 個中文字（約 3～5 分鐘），4～6 個段落，每句 `show` 不超過 30 字。
- 台灣用語、繁體字。個股一律「代號＋名稱」，例如「2330 台積電」「NVDA 輝達」。縮寫第一次出現要白話說明。
- `say`：英文人名、公司名、產品名保留英文字母（例如 Jensen Huang、Blackwell），不要寫成中文音譯；數字寫成念法（例如「四百五十億美元」）；年份、型號照念法寫。`say` 只放要念的字，不要加任何語氣指示。
- `en`：對應的簡短英文字幕。
- 用自己的話改寫，不要整句照抄來源文章。最後一段收尾一句「對你的意義」。

## 4. 配音
`python3 cloud/tts.py days/<日期>/script.json`
程式會自動聽寫檢查英文名有沒有被念成中文，最多重念 3 次。若最後回報有句子念不好，把那句的 `say` 換個說法（例如把英文名移到句首），刪掉 `days/<日期>/tts/` 裡那句的 wav，再跑一次。

## 5. 做影片
`python3 cloud/render.py days/<日期>/script.json`
然後用讀圖工具看 `days/<日期>/frames/` 裡第一張和字最多的一張，確認字沒有超出畫面、沒有亂碼。有問題就改 `show` 後刪掉 `segs/` 再跑。

## 6. 交付
- 用傳檔工具把 `days/<日期>/video.mp4` 傳給 KY（status 用 proactive），說明一行：主題＋長度。
- `git add days/<日期>/script.json days/<日期>/tts/report.json && git commit -m "<日期> 雲端版：<title>" && git push origin HEAD:main`
- 最後回覆（繁體中文，3～5 行）：今天的主題、結論一句、影片長度、有沒有念不好的英文名、來源連結。
